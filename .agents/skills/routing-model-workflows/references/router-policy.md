# Router policy

## Route dimensions

1. Privacy: local-only, private cloud or public-safe.
2. Evidence: current primary sources, supplied documents or reasoning only.
3. Execution: chat, repository, browser, filesystem, image, video or compute.
4. Cost: free allocation, subscription, API, cloud credit or local hardware.
5. Risk: reversible draft, repository change, external publish or destructive
   action.

## Default patterns

- Current research: cited search or official docs → synthesis → fact review.
- Repository change: implementer → tests → independent diff review → human
  publish gate.
- Long document: long-context model → structured extraction → domain review.
- Private material: local model or approved private surface → redact → cloud
  review only if needed.
- Repetitive transformation: script first; model only for judgment.

## Credit behavior

- Prefer an already-paid surface when quality is sufficient.
- Batch related work rather than opening repeated autonomous tasks.
- Switch models at a defined checkpoint, not during every uncertainty.
- Store personal benchmark results by task type; do not treat public
  leaderboards as absolute routing truth.
- Mark estimates as estimates.

## Stop conditions

Stop routing and ask for authority before:

- transmitting a private file to a new provider;
- using a different account;
- purchasing credits;
- publishing;
- expanding filesystem or browser permissions.
