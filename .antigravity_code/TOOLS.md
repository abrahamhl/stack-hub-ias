# HERRAMIENTAS NATIVAS Y CAPACIDADES DEL MOTOR ANTIGRAVITY (.antigravity_code/TOOLS.md)

## 🛠️ Herramientas Integradas del Motor Antigravity

Antigravity dispone de un conjunto de herramientas nativas que se ejecutan directamente en la sesión sin facturar al saldo personal del usuario:

| Herramienta | Tipo | Descripción |
| :--- | :--- | :--- |
| **`generate_image`** | IA Generativa Visual | Generación y edición de imágenes, mockups de producto, assets visuales e interfaces en tiempo real. |
| **`invoke_subagent`** | Multiprocesamiento | Instanciación de subagentes concurrentes (`research`, `self`, `architect`) con modelos `flash`, `pro` o `inherit`. |
| **`run_command`** | Terminal & Shell | Ejecución de comandos en PowerShell/Bash (Node, Git, npm, scripts en segundo plano). |
| **`view_file`** | Inspección | Lectura de archivos locales (código, imágenes, PDFs) con soporte para rangos de líneas. |
| **`write_to_file`** | Creación | Creación de nuevos archivos en el sistema de archivos con metadata de artefactos. |
| **`replace_file_content`** | Refactorización | Edición de bloques de código contiguos con verificación atómica. |
| **`multi_replace_file_content`** | Refactorización Masiva | Edición múltiple no adyacente en un mismo archivo. |
| **`grep_search`** | Búsqueda | Búsqueda ultrarrápida por ripgrep en todo el repositorio. |
| **`list_dir`** | Explorador | Listado recursivo de directorios y estructura de archivos. |
| **`schedule`** | Automatización | Programación de cron jobs y timers en segundo plano. |
| **`manage_task`** | Gestión de Procesos | Control y monitoreo de tareas en segundo plano (stdin, kill, status). |
| **`ask_question`** | Interacción | Modal interactivo para preguntas de opción múltiple al usuario. |
