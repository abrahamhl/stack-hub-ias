# Multi-Marketplace Scorer Skill

## Directivas Operativas
1. **Scoring Marktplaats NL**: Recomendar precio de venta optimizado para el mercado neerlandés en euros.
2. **Scoring Vinted**: Evaluar oportunidad de venta rápida europea.
3. **Generación de Bundles**: Agrupar prendas del mismo estilo/talla en lotes con un 15% de descuento comercial.
