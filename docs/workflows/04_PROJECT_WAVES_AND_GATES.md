## Oferta SaaS

La hipótesis `1.500 € setup + 500 €/mes` no se publica como promesa hasta
validar una vertical, fuente legal, tres demos, alerta accionable, ahorro/ingreso
y costes reales.

## APIs y créditos

Antes de pagar o activar Google Cloud: inventario de créditos/caducidad,
proyecto exacto, budgets/alertas, API mínima, cuotas/kill switch, owner, prueba
de coste y aprobación. Claves solo en secret manager, credential store o `.env`
ignorado.

## Carril rojo

### Cámaras

Contar afluencia agregada podría evaluarse con minimización y procesamiento
local. Inferir emociones, intención de compra o perfilar personas queda fuera
del MVP. Requiere revisión legal, proporcionalidad, DPIA cuando proceda,
cartelería, retención mínima y control de acceso.

### Face swap

Solo material propio o con consentimiento verificable, trazabilidad y
etiquetado. No se prueba evasión de censura ni suplantación.
